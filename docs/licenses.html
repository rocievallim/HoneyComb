Honeycomb for macOS 2.0.2

Honeycomb’s Mac app incorporates and adapts native editor code from Open Tangerine for Honeycomb’s interface and workflows. The combined Mac app is distributed under GNU GPL version 3 only. The separately built Filee helper and the original MIT-licensed components retain their respective notices and terms.

Conversion tools

System frameworks are supplied by the operating system. Third-party conversion tools installed through package managers or fetched from their upstream releases carry their own licenses. The Windows installer includes the compiled Honeycomb application. Conversion engines, including the optional Filee CLI, are installed separately under their upstream licenses.
